# i18n — som-blocks

- Languages v1: `es` (default, Chilean Spanish, tú form) and `en`. Planned: pt, zh-Hans, ja, fr, it, de.
- Two message layers, both keyed: (1) Blockly core messages (ship with Blockly per locale); (2) our block + UI messages in `src/i18n/<lang>.json`, flat keys namespaced by family (`ESPNOW_SEND_TO`, `UI_COMPILE`).
- Rules: one key per literal even if text repeats; all languages edited together in the same PR; missing key falls back to `es` and fails a CI check that lists untranslated keys.
- Audience 10–14: short imperative labels, no jargon on the starter toolbox; technical terms allowed in the full toolbox and code view.
- Locale picked from URL `?lang=` > saved preference > browser language.
